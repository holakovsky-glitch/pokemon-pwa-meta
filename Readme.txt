# Návod - Ako uložiť súbory na GitHub (pre Petra)

Tento návod je napísaný jednoducho, krok za krokom. Nepotrebujete inštalovať žiadny program.

## Čo budete potrebovať
- počítač s internetom
- účet na GitHub (zdarma na github.com)
- 7 súborov, ktoré ste dostali od Meta

## KROK 1 - Vytvorenie účtu (ak ho nemáte)
1. Otvorte github.com
2. Kliknite "Sign up"
3. Zadajte email, heslo, meno (napr. peter-veterinar)
4. Potvrďte email

## KROK 2 - Vytvorenie nového repozitára
1. Po prihlásení kliknite vpravo hore na "+" a vyberte "New repository"
2. Do poľa "Repository name" napíšte: pokemon-pwa-meta
3. Zaškrtnite "Add a README file"
4. Kliknite zelené tlačidlo "Create repository"

## KROK 3 - Nahratie súborov
1. V novom repozitári kliknite na "Add file" → "Upload files"
2. Potiahnite myšou všetkých 7 súborov do okna, alebo kliknite "choose your files" a vyberte ich:
   - profil-peter.txt
   - profil-projekt.txt
   - infoV8.73.txt
   - pokracovanie-pre-Meta.txt
   - celebration.js
   - test-oslava-final.html
   - index-8.73-pin-visible.html (ten už máte)
3. Dole do poľa "Commit changes" napíšte: "Prvé nahratie súborov"
4. Kliknite "Commit changes"

## KROK 4 - Získanie linku pre Meta
1. Kliknite na súbor pokracovanie-pre-Meta.txt
2. Kliknite tlačidlo "Raw" (vpravo hore)
3. Skopírujte adresu z prehliadača - bude vyzerať takto:
   https://raw.githubusercontent.com/VASE-MENO/pokemon-pwa-meta/main/pokracovanie-pre-Meta.txt
4. Tento link pošlite Mete v novom čete

## KROK 5 - Ako upravovať súbory neskôr
1. Otvorte súbor v GitHub
2. Kliknite ikonku ceruzky "Edit"
3. Upravte text
4. Dole kliknite "Commit changes"

## Dôležité
- Všetko je zdarma
- Súbory sú súkromné, ak pri vytváraní zvolíte "Private"
- Meta si vie stiahnuť súbory cez "Raw" link

Ak niečo nejde, napíšte Mete presne v ktorom kroku ste sa zasekli.
